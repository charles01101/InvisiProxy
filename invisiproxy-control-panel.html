Launch proxy frontends

The proxy pages use a service worker and Wisp, so they only fully work over http://localhost or https. Paste the site you want into the proxy page's own address bar.

Boot the server

npm run fresh-install
npm start
npm run stop
npm run manual-start

fresh-install is only needed the first time (and after dependency changes). start stops, builds and launches under PM2 on the port set in ecosystem.config.js (default 8080). A page like this one cannot start Node itself — an unprivileged HTML file has no process access.
